# 📊 Dashboard d'Analyse des Ventes - Power BI

## 📌 Présentation du Projet
Ce projet consiste en un tableau de bord interactif conçu sous **Power BI** permettant d'analyser les performances commerciales et les ventes d'une entreprise. L'objectif est de transformer des données brutes en indicateurs clés de performance (KPI) visuels et exploitables pour faciliter la prise de décision stratégique.

---

## 🎯 Objectifs Métier
- **Suivi global de l'activité** : Visualiser le chiffre d'affaires, le volume de ventes et les marges réalisées.
- **Analyse temporelle** : Identifier les tendances mensuelles/annuelles, la saisonnalité et la croissance des ventes.
- **Performance par segment** : Analyser les ventes par catégories de produits, zones géographiques et segments de clients.
- **Prise de décision basée sur la donnée** : Fournir une vue synthétique pour orienter les actions commerciales.

---

## 🛠️ Stack Technique & Outils
- **Business Intelligence** : Power BI Desktop
- **Langage de modélisation & calculs** : DAX (Data Analysis Expressions)
- **Préparation de données** : Power Query (ETL)
- **Stockage / Versioning** : GitHub

---

## 📊 Structure du Rapport & Fonctionnalités
1. **Vue d'ensemble (Executive Overview)** : KPIs principaux (CA total, nombre de commandes, panier moyen, marge globale).
2. **Analyse Détaillée des Ventes** : Graphiques d'évolution dans le temps, répartition géographique et classement des meilleurs produits/clients.
3. **Filtres Dynamiques** : Filtrage interactif par période, région et catégorie de produits.
